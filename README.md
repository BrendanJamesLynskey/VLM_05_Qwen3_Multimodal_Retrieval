# VLM 05 — Qwen3-VL for Video Analytics: Clip Retrieval, Temporal Grounding & Edge Deployment

A deep-technical presentation on building video analytics from one model family: **Qwen3-Embedding-VL** for clip-level retrieval, **Qwen3-Reranker** for temporal-aware cross-encoder rescoring, and **Qwen3-VL** as the long-context analyst that returns timestamps and bounding boxes from the original footage. Covers M-RoPE positional encoding, frame sampling and clip chunking (uniform / scene-change / motion-adaptive), the bi-encoder vs cross-encoder trade-off, calibrated rerank thresholding, edge-vs-cloud deployment topology, and Qwen3-VL MoE sizing (A3B, A22B).
